# 🚀 Step-by-Step Implementation Plan: Orient Computers & Engineering
**Tech Stack**: **React (Vite) + Node.js / Express + MongoDB (Mongoose) + Tailwind CSS**

---

## 🏗️ Project Architecture Overview

```
orient-computers/
├── server/               # Node.js + Express REST API Backend
│   ├── config/           # Database connection (MongoDB / Mongoose)
│   ├── controllers/      # Route controllers (auth, products, orders, etc.)
│   ├── models/           # Mongoose schemas (User, Product, Category, Order)
│   ├── middleware/       # JWT Auth & Admin authorization middleware
│   ├── routes/           # Express API endpoints
│   ├── utils/            # Seeder scripts & helper functions
│   └── server.js         # Backend entry point
│
└── client/               # React (Vite) Frontend
    ├── src/
    │   ├── assets/       # Banners, logos, placeholder images
    │   ├── components/   # Reusable UI (Header, Footer, ProductCard, SpecsTable, etc.)
    │   ├── context/      # Global State (AuthContext, CartContext, WishlistContext)
    │   ├── pages/        # Views (Home, Shop, ProductDetail, Cart, Checkout, Admin)
    │   ├── services/     # Axios / API client calls
    │   ├── types/utils/  # Formatting helpers (Currency BDT, date formatters)
    │   └── App.jsx       # Root router setup
```

## 🔌 Phase 3: Backend REST API Development

- [x] **Step 3.1: Authentication & Authorization Middleware**
  - Implement JWT authentication verification middleware (`protect`).
  - Implement Admin role verification middleware (`isAdmin`).
- [x] **Step 3.2: Auth Endpoints (`/api/auth`)**
  - `POST /register` – Register new customer with password hashing.
  - `POST /login` – Authenticate user and return JWT token.
  - `GET /me` – Fetch logged-in user profile.
- [x] **Step 3.3: Product Endpoints (`/api/products`)**
  - `GET /` – Fetch products with dynamic multi-filtering (category, brand, price range, stock, search keyword, sorting, and pagination).
  - `GET /featured` – Fetch featured items, flash deals, and new arrivals.
  - `GET /:id` – Fetch single product with technical specs and reviews.
  - `POST /` – (Admin only) Create new product.
  - `PUT /:id` – (Admin only) Update product details/stock/price.
  - `DELETE /:id` – (Admin only) Delete product.
- [x] **Step 3.4: Order Endpoints (`/api/orders`)**
  - `POST /` – Create new customer order.
  - `GET /my-orders` – Fetch current user's order history.
  - `GET /:id` – Fetch specific order details with status timeline.
  - `GET /` – (Admin only) Fetch all store orders with status filter.
  - `PUT /:id/status` – (Admin only) Update order fulfillment status.
